# Pulse — тестовый сайт с анимациями

Одностраничный сайт-витрина анимаций на **React + Vite + framer-motion + three.js**, HTML, CSS и JavaScript.

## Эффекты

- Светлая и тёмная тема: переключатель в шапке, новая тема раскрывается кругом из точки клика (View Transitions API), выбор запоминается
- Детальные 3D-часы на three.js (React Three Fiber) с мягкими тенями и текстурами 2K: кожаный ремешок со строчкой, ротор автоподзавода с гравировкой, окно даты с реальным числом, гильоше на циферблате, гранёные стрелки и люминофор, круговое шлифование колёс, полированные фаски мостов, регулятор хода; корпус, купольное стекло, циферблат с накладными индексами, стрелки с реальным временем, платина с перляжем, мосты с женевскими полосами, рубины, синёные винты, колёсная передача, анкерный спуск, баланс с волосковой спиралью
- Секция «Механизм»: при прокрутке камера разбирает часы и подлетает к колёсной передаче, спуску и балансу, в конце — полный разлёт деталей
- У каждой секции своя палитра: при прокрутке весь сайт плавно перекрашивается (CSS `@property`)
- Бургер-меню справа вверху: открывается круговой маской, пункты появляются по очереди
- Точки-навигация по секциям справа
- Блоки появляются при прокрутке по-разному: с размытием, с боков, с поворотом, с 3D-переворотом, и анимируются снова при каждом возврате
- Буквы заголовка появляются по одной с 3D-поворотом, слово в заголовке сменяется с размытием
- Плавающие светящиеся блобы и движущаяся сетка на фоне (CSS keyframes)
- Свечение, которое следует за курсором (пружинная физика)
- «Магнитные» кнопки, которые тянутся к курсору, и блик на кнопке
- Полоса прогресса прокрутки
- Карточки с 3D-наклоном и подсветкой за мышью
- Появление блоков при прокрутке со ступенчатой задержкой
- Счётчики, которые считают до нужного числа
- Параллакс: фигуры двигаются с разной скоростью
- Бегущая строка (пауза при наведении)
- Табы с перетекающей подложкой (layout-анимация)
- Аккордеон с плавным раскрытием
- Частицы на canvas, которые разбегаются от курсора

Если в системе включено «Уменьшить движение», CSS-анимации отключаются.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, результат в папке `dist`.
